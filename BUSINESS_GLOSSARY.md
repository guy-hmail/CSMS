# BUSINESS_GLOSSARY.md

| Term | Definition |
|---|---|
| Church | Tenant of the system |
| Organization Unit (OU) | Node in hierarchy |
| Leaf OU | Lowest OU that normally submits statistics |
| Submission | Weekly statistics header |
| Metric | Configurable KPI definition |
| Statistic Value | Value of one metric in a submission |
| Reporting Period | Week, month or custom period |
| Dashboard | Aggregated KPI view |
| Approval | Validation workflow before official reporting |
| Manager | User who manages an OU and descendants |
| Approver | User allowed to approve submissions |
| Data Entry | User allowed to submit statistics |
| Viewer | Read-only user |
| Override | Higher approver approves/edits lower OU submission |
